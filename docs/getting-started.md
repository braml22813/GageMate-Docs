# Getting Started

1. Launch GageMate.
2. Import a CSV file with appropriate headers and numeric measurement data.
3. Select the analysis module matching your study objective.
4. Configure the measurement column, study factors, specification limits, and confidence or significance settings as applicable.
5. Run the analysis and inspect the charts and statistical report.
6. Independently validate results before making consequential quality decisions.

## Available modules

- ANOVA Gage R&R (Crossed, Nested, Expanded)
- Type 1 Gage R&R
- Attribute MSA
- Capability & Performance Analysis
- Normality Testing
- Distribution Analysis
- Basic Statistics
- SPC Charts
- Curve Fit
