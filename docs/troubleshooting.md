# Troubleshooting

## Download is blocked

Confirm that the URL is the official publisher's release page. On managed devices, ask IT to review the download. Do not disable browser or endpoint protections.

## Windows displays an unknown-publisher or SmartScreen warning

Review the release source, checksum, and signature status. If your organization manages the device, ask IT for authorization. A warning does not automatically establish that a file is malicious or safe.

## Installer requests administrator permission

An installation under Program Files may require elevation. Contact your administrator rather than changing device policy.

## GageMate does not start

Record the Windows edition/build, GageMate version, installation path, and any visible error. Retry only according to approved troubleshooting procedures; report repeatable errors to the publisher.

## CSV import or analysis fails

Confirm column headers, numeric values, missing data, and module-specific study requirements. Reproduce with non-sensitive sample data where possible.

## Reporting an issue

Provide the release version, steps to reproduce, expected behavior, observed behavior, and a screenshot with sensitive information removed. Add the publisher's verified support link here.
